# NexumNTL

**Introduction**
--------

NexumNTL is a compiler project I've been working on, so far on my own. All code and concepts are 100 human made. 

NexumNTL stands for Nexum Neurotransmission Language. The language carries out several roles within my larger, custom
built Nexum Intelligence Framework. The Nexum Intelligence Framework is a cognitive  substrate aimed around generating 
effecient, smart, non LLM/Bayesian inspired AI agents. NexumNTL is named Nexum Neurotransmission language because it's 
original role was to handle transmitting data between Cognitive Units (a term specific to the substrate) within the
Neural/Reasoning network.

**Core Concepts**
--------

NexumNTL was designed first and foremost as a way to compress and tokenize the English language. This is accomplished through
morpheme level parsing and encoding. A morpheme is the most basic building block of English verbage. Morphemes are encoded in
efficient, compressed forms to form words from compressed morphemes.
